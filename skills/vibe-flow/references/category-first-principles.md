# 多范畴第一性推演

本参考只在事实、因果或预测存在高影响不确定性，而且不同范畴可能改变技能选择或执行网络时使用。它不是固定专家名单，也不是第四道 Agency Protocol 闸门。

## 基本定义

### 共同对象

所有范畴必须研究同一个对象、命题或决定。先写清：

- 需要解释或预测的对象；
- 当前要做的决定；
- 哪些新证据可能改变该决定。

多个范畴必须指向同一对象，但不得预设相同结论。强迫所有专家支持同一结论会制造确认偏误。

### 范畴

范畴不是职位名称，而是一组相对独立的：

- 基本对象与不可继续拆解的事实；
- 因果模型；
- 可接受证据；
- 约束与失败条件；
- 能够导出的行动。

两个专家依赖相同事实、相同因果链和相同证伪条件时，应合并为一个范畴。

### 范畴内第一性原理

第一性原理不是脱离上下文的绝对真理。它是在给定范畴与任务边界内，继续拆解已经不能增加当前解释力的事实、约束或因果关系。

每条第一性原理必须满足至少一项：

- 可由项目事实、权威资料或直接观察支持；
- 是用户、系统或现实环境明确给出的不可违反约束；
- 能导出可被证伪的不同预测；
- 删除后，该范畴的推演链无法成立。

口号、职业偏好和无法证伪的价值陈述不能冒充第一性原理。

## 启动门禁

满足以下全部条件才运行：

1. 共同对象和决策已明确；
2. 不确定性属于事实、因果或预测，而不是人的价值所有权；
3. 至少存在两个可能改变行动的独立范畴；
4. 分歧能够产生可检查证据或不同任务；
5. 普通检查不足以用更低成本解决。

任一条件不满足，跳过本流程。

## 选择最小专家团

根据上下文生成候选范畴，不使用固定职业清单。通常保留二至四个。

对每个候选回答：

| 检查 | 问题 |
| --- | --- |
| 独特基本事实 | 它知道什么是其他范畴不知道的？ |
| 独特因果模型 | 它如何解释对象变化？ |
| 独特证据 | 它需要什么不同数据或观察？ |
| 独特证伪条件 | 什么结果会只推翻它？ |
| 行动差异 | 它成立会怎样改变技能或任务网络？ |
| 相关成本 | 其上下文、等待和验证成本是否值得？ |

没有独特答案的候选应合并或拒绝。不要为了看起来全面而保留重复视角。

默认由同一执行者进行隔离的范畴切换。只有在以下条件同时成立时才值得使用真实并行专家：

- 每个专家可以从稳定且相互独立的证据开始；
- 不会竞争同一判断、文件或资源；
- 并行结果有明确的汇聚消费者；
- 当前运行环境与用户授权允许并行委派。

## 独立推演格式

每个范畴先独立完成第一轮，不读取其他范畴的结论：

```text
范畴：
共同研究对象：
该范畴的第一性原理：
不可违反的约束：
关键假设：
因果推演：
预测或判断：
置信度及其依据：
支持证据：
证伪条件：
如果成立，对技能和任务网络有什么影响：
```

置信度优先使用高、中、低或有条件区间。只有存在历史校准、可比较基线或明确统计模型时才给精确概率。

## 概率边界

必须分开两种概率：

```text
P（判断成立｜范畴、证据）
```

这是认知概率，用于表达某项因果或事实判断在特定模型下的可信程度。

```text
P（按期完成｜任务网络、工期、资源）
```

这是进度概率，用于统筹网络中的时间风险。

不得把多个未经校准的专家数字直接平均。综合权重只能来自：

- 与当前对象的相关性；
- 证据质量；
- 与其他范畴的独立程度；
- 过去预测的校准记录；
- 证伪条件是否明确。

没有这些依据时，报告置信等级和决定性证据，不输出伪精确总概率。

## 汇聚，不投票

将结果整理为：

### 稳健交集

不同范畴通过不同因果链得到的共同结论。记录各自证据，避免把相关证据误当独立重复证明。

### 条件结论

只在某项假设或边界成立时有效。保留条件，不把它升级成无条件结论。

### 关键分歧

结论不同且会改变行动。不得以多数票解决，改写成：

```text
冲突命题：
各自依赖的关键假设：
能够区分它们的决定性证据：
获得证据的任务：
证据消费者：
继续门禁：
```

只有会改变技能选择、主要矛盾线、资源配置或终局验收的分歧才进入执行网络。其余记录为低影响不确定性。

## 转化为统筹输入

专家和范畴不是华罗庚统筹网络中的任务节点。把输出转换为可观察工作：

- 假设需要数据支持 → 数据收集或测量任务；
- 因果模型冲突 → 能区分模型的实验或对照；
- 风险边界不清 → 风险验证或授权门禁；
- 已形成稳健结论 → 直接成为技能裁决证据；
- 无法验证且会实质改变结果 → 标为阻塞，不继续猜测。

每个证据任务必须拥有：

`所有者 → 输入 → 输出证据 → 时长或区间 → 资源 → 消费者 → 门禁`

然后交回 Vibe-Flow 完成技能裁决、网络建模、主要矛盾线和动态重算。

## Agency Contract 映射

- 范畴事实、推演链和预测来源 → `evidence`
- 多范畴稳健结论 → `decisions.locked` 或 `decisions.provisional`
- 仍会改变行动的事实冲突 → `decisions.open`
- 人的价值冲突 → 保持 human-owned Open，返回意图闸门
- 决定性验证任务及其输入 → `handoff.inputs`
- 通过后允许继续的条件 → `handoff.continuation_gate`
- 会推翻结论的证据 → `handoff.reopen_if`
- 可观察验证方法 → `acceptance_criteria`

不要给 Agency Contract 增加同义字段。只有真实测试证明 v0.1 无法承载时，才提出新版本。

## 完成条件

多范畴推演完成于：

- 每个准入范畴都有独特因果模型或证据；
- 人的价值判断没有被专家替代；
- 共同结论保留了证据来源；
- 关键分歧已转化为证据任务或明确阻塞；
- 没有用投票或伪概率掩盖冲突；
- 下一步可以进入技能裁决或华罗庚统筹网络。
